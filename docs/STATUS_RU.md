# Состояние версии r4

Подготовлена версия `2026-10-07-r4` для разрешённой публичной публикации. Исходные r2/r3 и все 161 перенесённый файл доказательств сохранены без изменений. Код проверки, тесты и исследовательские выводы не изменены. Изменены только документация, манифест и сведения о выпуске. Splunk, ADX, модели и исследовательский Python повторно не запускались.

Подтверждены имя Akylbek Ongarbekov, репозиторий `Drum1er/security-rule-evaluator-small-study`, публичная публикация, краткое описание вклада в README и подробное описание в `AI_ASSISTANCE.md`. Предыдущий план закрытой первой загрузки заменён разрешением публичной публикации.

Условия установленного Splunk и Trial 500 MB получены; общего запрета на раскрытие любых результатов в проверенном договоре не установлено. Исходный SPL LSASS связан с Apache-2.0 правилом Splunk security_content. Включённый KQL создан RulePilot и опубликован в статье под CC BY 4.0; это не другой вывод Microsoft SPL2KQL из той же иллюстрации. Лицензионные уведомления сохранены, исторические записи не переписаны.

Остаётся узкая неопределённость: полный текст дополнительных условий бесплатного ADX-кластера получить не удалось. Это не установленный запрет; разрешение публикации не означает, что эта оговорка снята. См. `../PUBLICATION_BLOCKERS.md`.

Результат проверки именно этого конечного ZIP, команды, коды завершения, число файлов и SHA-256 записаны в отдельном `portfolio-project-2026-10-07-r4.validation.json` рядом с ZIP. Только этот отчёт определяет статус выполнения офлайн-тестов r4; результаты r2/r3 не переносятся автоматически. Ни отчёт, ни контрольная сумма не помещаются внутрь проверяемого ZIP.

Учебный пример [OWNER_GUIDE_RU.md](OWNER_GUIDE_RU.md) предлагает вопросы для самостоятельной проверки. На момент фиксации пакета загрузка r4 на GitHub ожидает проверки удалённого коммита, полного состава файлов и публичной видимости.
