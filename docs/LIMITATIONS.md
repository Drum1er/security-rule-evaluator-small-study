# Limitations and unresolved evidence

- **Sampling:** four deliberately constructed native cases, two published pairs, one quantized local model and a single saved judgment per case. There is no population accuracy estimate, uncertainty interval or evidence of statistical independence.
- **Adaptation:** synthetic inline sources replace production indexes and the unpublished `sysmon` macro. Ingestion, alerting, macro expansion and Sentinel deployment were not tested. Hosted Azure Data Explorer is not Sentinel.
- **Captures:** Splunk results are internally consistent user-returned exports, not signed engine attestations. Kusto used UI Copy-as-datatable exports. DNS witness has a completed empty grid with column names but no captured native type metadata. Historical empty LSASS SPL output similarly lacks column metadata.
- **Time and order:** an explicit adapter handles timezone-qualified SPL `_time` strings and verifies the separate `diagnostic_time_epoch` field. Some final-rule queries preceded input-only diagnostics. Later input checks do not retroactively satisfy the original wrapper-first protocol. A frozen `not_run` label in `examples/native/frozen-runs.json` is the preparation state, superseded by subsequent result evidence.
- **Repetition:** the packaging session did not rerun engines, the model, ARuleCon or generated Python. Offline verification proves consistency of saved bytes under this verifier, not independent live reproducibility. Kusto's server build was not captured.
- **Component execution:** the historical work extracted pinned components, replaced the API with a local model, used synthetic data and replayed responses. Full SDK/RAG orchestration was not reproduced. The source chain finished 4/4 steps; the target stopped at 4/6. No held-out witness or final comparator followed.
- **Infrastructure corrections:** v1 supplied dictionaries where JSON strings were needed; v2 reached a generation timeout; v3 retried one request with a larger limit; a launcher flaw could let a closed-stdio child outlive its limit. One earlier call used that old launcher. v4 hit an output transport limit and was initially mislabeled as nondeterminism; v5 removed repeated prompt copies without increasing the limit. These corrections do not make earlier execution guarantees retroactively valid. See the retained [lifecycle hold](../results/partial/LIFECYCLE-HOLD.json) and the private original archive for the full sequence.
- **Causal scope:** the first-step prompt change preserved records in LSASS and Microsoft. LSASS selection errors remained, both MITRE arms missed expected records, and DNS was excluded. This is not a universal fix.
- **Missing pilot:** initial `__row` tests, corrected `rownum` pilot queries/results and their model rerun are not included. The owner reports six corrected SPL executions. Present native wrappers use `rownum`; that does not prove the missing pilot outcomes.
- **Attribution:** personal activities are owner-reported. Additional historical reviews were AI runs, not independent human expert review. Owner understanding and an owner-run reproduction are not yet demonstrated.
- **Publication:** third-party and vendor rights remain subject to [specific blockers](../PUBLICATION_BLOCKERS.md). Byte hashes and repository licenses cannot clear proprietary-service result publication.
